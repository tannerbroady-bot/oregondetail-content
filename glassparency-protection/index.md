# GlassParency Windshield Coating in Eugene, OR

## What is GlassParency?

GlassParency is a professionally applied glass coating that improves visibility in bad weather: water micro-beads and sheets off the windshield, and night glare is greatly reduced.

It is a two-part chemical application engineered to react only with glass (silica). It is not a wax or topical treatment; it is a long-term treatment for vehicle glass.

Every GlassParency automotive application is backed by a 3-year product warranty, which covers performance as long as the glass is properly maintained.
